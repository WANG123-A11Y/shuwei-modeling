# 限时流程与英文论文

## 接续与时间

先读状态和剩余时间；未知就用阶段，不虚构赛程。可先按审题附件 10%、基线主模型 35%、验证 20%、整合写作 25%、交付检查 10% 规划，再按风险调整。比例是工作建议，不是官方要求。

| 阶段 | 达标产物 | 主要风险 |
| --- | --- | --- |
| 审题 | 每问交付表、数据清单、方法与理由 | 题意、单位、缺附件、标签错配 |
| 基线 | 端到端结果、小算例、初步图 | 无法执行、不可行、读取错误 |
| 主模型 | 各问结果、真实运行记录、图表数据 | 泄漏、未来信息、漏约束、无验证 |
| 验证 | 基线比较、敏感性/误差/可行性 | 不公平比较、假敏感性、过度解释 |
| 成稿 | 题目—模型—结果—图表对应 | 摘要数字漂移、缺出处、漏任务 |
| 交付 | 本届规范、最终渲染、可复现材料 | 匿名、错文件、溢出、未实际提交 |

缺数据时拆清可做与不可做。可推导、实现读取器、准备计算和写假设；不能把模拟数据当官方附件结果。

## 必要实验

按任务选择：人工可查/已知解算例；有意义的同口径基线；关键参数真实扰动重算及必要消融；独立验证或约束/守恒/收敛；失败/边界情形。有随机性且预算允许做多种子，预算不足写限制。无需为形式强制 SOTA 复现、全模型网格搜索或大量重复图。

## 逐问写作

写清回答什么、输入是什么、为何这样建模、如何求解、实际结果、证据边界。按实际问题组织，不强制期刊 IMRAD。

每段先确定主张、依据、解释与下一段关系。先数据/物理逻辑，再算法细节。符号首次定义且一致；单位、上下标、初值、约束、时间窗同代码对应。

## 英文 Summary

最后写，核对本届篇幅。覆盖目标、方法假设、各问关键结果、验证、局限与建议；不能只列模型名。可使用句式骨架：

> For Task [n], we formulate [model] using [inputs] under [assumptions]. On [evaluation set/scenario], [measured result with unit]. Compared with [baseline], [supported difference]. The result is limited by [specific boundary].

不能填造数字；没有结果标 pending，区分草稿与终稿。提升百分比核实分母，百分点单独表达。英文清楚具体，optimal/robust/real-time 等要有证据。已确认英文规则时检查图内文字、轴名、图注、表头和正文；讨论可中文。

## 图表与文献

每图回答一个问题，从结果文件生成并保留代码/数据。查轴单位、对数刻度、图例、误差条定义、样本量、测试集和时间窗；比较同口径。

地图标投影、分级、NoData、尺度；敏感性图标变化参数、范围与重算指标；优化图标前沿和推荐点。训练曲线不代替测试。精确数据图不得用生成式图像画。

最终尺寸查看可读性、裁切、字体和公式。导出 DOCX/PDF 要渲染，不能只查文本。

文献条目存在与支持论断分别核验。查原文/出版者/DOI，核作者、题名、年份、期刊页码，核引用处的具体主张；题面参考资料不免核查。无法证实写【未核验】，不编条目。正文文末对应；数据来源保留链接、版本与访问日期。不默认用中文期刊/Nature 格式。

## 终审四遍

1. 题目与论证：各问/交付齐全，模型和假设支持所问，无模板残留。
2. 数值与证据：摘要结论逆查图表、指标、运行、配置、输入；核 MSE/RMSE、百分比、单位、约束和时间窗。
3. 表达与引用：语法、术语、符号、来源、结论强度；清理无证据的创新、最优和部署声称。
4. 成品与规范：本届页数、匿名、字体、公式图表、命名、材料清单；查看最终渲染与实际交付文件。

改动影响方法/数值/结论时同步摘要、正文、图表、结论和附录。自动扫描是特定诊断，不等于全面通过。结束时先报告真实阻塞和检查范围；用户要求评分时说明非官方标准，并先过来源、逻辑和未核验信息三关。
