# 独立判断与三级审核

每次修改模型、代码、数据处理、论证、图表、引用、格式或技能规则后，对受影响范围依次审核。用户提出的三项原则为强制约束。

## 独立判断与建议格式

先读实际材料，再下判断。用户、作者、获奖标签、复杂算法、其他 AI 的一致意见均不能替代证据。优先处理有效性问题；没有证据也不制造问题。区分确定错误、待核疑点、适用边界与偏好建议。

每条重要修改建议给出：原文位置、实际证据、问题及后果、有限修复、复验办法。没有读到的内容明确说明；不能以关键词命中或全文提取代替完整审阅。

## 第一级：事实来源

对所有新增/受影响的数据、案例、参数、规则、引用和具体结论核查：

- 来源确实存在并已读取；保留文件/原始 URL、版本/日期、PDF 物理页、表/字段/代码位置。必要时记录文件 SHA256。
- 数据、案例、参数、规则、引用的原始来源必须可追溯到合集内文件或题目原文；无法追溯的显式标【未核验】，不得写成事实。
- 凡依赖论文材料的判断，一律标【待论文补充】，不得在论文未提供时下确定性结论。
- 原文支持这个具体说法；样本、时间空间、单位、比较分母、聚合与统计口径一致。
- “某论文报告了一个数值”与“该数值经独立复现正确”分开。只读论文能核实前者，不能认证后者。
- 文献逐项核作者、题名、年份、出版来源和 DOI/标识；题面推荐、搜索摘要与 AI 列表也不能直接当已核验参考文献。
- 外部技能核作者原仓库、版本、实际入口/依赖、许可信息。自称工业级/获奖级不算效果证据。

发现缺失/错配先 FAIL。通过补来源、纠正口径、缩小主张或移除无据断言修复。文件存在、URL 可访问、哈希一致只证明特定记录，不证明科学结果正确。

## 第二级：逻辑合理性

当前候选第一级通过后再检查：

- 问题→假设→变量→模型→算法→结果→结论闭合，实际回答所问。
- 量纲、符号、换算、初边值、质量/守恒、可识别性、可观测性、约束与求解状态一致。
- 检验和划分符合实验单位、配对/重复结构与时空依赖；无训练/测试/任务间泄漏。
- 指标代数、改善方向、百分比/百分点、加权/平均、基线和独立评估口径正确。
- 不把拟合当预测、相关当因果、评分当概率、启发式最好解当全局证明、图形缩放当模型敏感性。
- 建议可执行且适合数据、算力、时间和本届已核实规则。

错误则 FAIL，返回修改并从第一级复验。不能因原论文也这样做而跳过。关键公式提取不清要看原页；仍不清楚记待核，不凭乱码“修正”。

## 第三级：未经证实信息

第二级通过后检查最终表述：

- 区分【已核验事实】【文献报告】【推导】【假设】【未核验】，不将不同证据身份互换。
- 无法确认的数据/引用明确标【未核验】，记录原因、影响与补证办法；不再在摘要/结论中据此作确定性论断。
- 未经证实的内容有且仅有两种处理方式：剔除，或显式标【未核验】后保留；不得以“可能”“大概”等模糊表述蒙混过关。
- 每轮三级审核记录必须写明：候选范围、每级结果（PASS / FAIL / NOT_RUN）、定位发现、修复动作。
- 不增加未知运行、样本数、精度、显著性、创新、实时性、最优性、实际效果或获奖承诺。
- 不把自动扫描、模型自评、多人一致或文件齐全说成正确性证明。
- 如实报告阅读深度、运行范围、未完成项与安装状态；全文提取不等于全文精读。

存在隐瞒、无证升级、漏标或过度确定性则 FAIL，返修并从第一级复验。

## 修订与最终交付

每轮保留候选版本/文件哈希、改动、按序的三级结果、定位发现、处置与残留。状态只使用 PASS / FAIL / BLOCKED / NOT_RUN；前级失败后，后级为 NOT_RUN。

不得拼接不同版本的 PASS。任何实质修改都使旧候选审核失效，受影响内容从第一级重新审查。文风小改可简短记录，数值/代码/整篇修改保留结构化证据。

只有同一候选三级均 PASS 才输出该范围最终内容。证据客观不可得时，不无限重复、不伪造通过；阻塞相关部分，对缩小后能支持的交付范围重新审核，并说明未核验项。阻塞报告不等于整项工作完成。

审核记录示例结构与命令见 `audit_review.py --help`。该脚本仅检查顺序、状态和候选是否改变；实质来源支持与逻辑需要阅读、推导或复算。
